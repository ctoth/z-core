z-core

A deterministic Z80180/Z8S180 CPU and SoC emulator, written in Rust for native, Python, and WebAssembly hosts.

Open the firmware workbench

Try it in your browser

The included counter is ready to run. Select Run to stop on a write to RAM at 0x1000, then Back to inspect the instruction responsible. Step through instructions, inspect registers and memory, and export a session to revisit later.

You can also load your own ROM. Execution and session files stay in your browser. The workbench models a bare board; firmware that needs external devices requires a host integration.

Build with z-core

The core includes the CPU, MMU, interrupts, timers, serial interfaces, DMA, tracing, and save states. It uses no_std with alloc and forbids unsafe code.
